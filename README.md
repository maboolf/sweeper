### [Current game version: 0.5]

**Welcome!** This is my first *'real'* C++ project!

## ABOUT 
**Sweeper** is my attempt at creating a working Minesweeper program, in C++! 
**Sweeper** is largely quite simple, being *confined to the console for now*, but later versions
(0.9+) will hopefully be made with a GUI window, including textures, sounds, and so on.

This project is a bit of a learning experience, being the first real test of my C++ knowledge since
starting it only a month or two ago for my university course.

## PROGRAM INFO  
I'm currently developing this on both my Windows desktop PC, and my Linux laptop, so the final
product should support both.
Compilation of the program at this time does require a minimum CMake version of 4.3.0 (the version
I'm using). I can't think of any other system requirements at this time, but I also still don't
really know how to build the damn thing, so there may be some requirements I don't even know.
